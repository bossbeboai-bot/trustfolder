## Notice

{{ product_name }} generates {{ content_types_human }} using artificial intelligence. This notice describes how AI-generated outputs are marked, in accordance with Article 50(2) of the EU AI Act (Regulation (EU) 2024/1689).

## What is "AI-generated content"

For the purposes of this notice, "AI-generated content" means {{ content_types_human }} produced or substantially modified by an AI system, including outputs from {{ #if third_party_models }}{{ third_party_models }}{{ else }}underlying AI models{{ /if }}.

## How we mark AI-generated outputs

### Human-readable disclosure

All AI-generated outputs from {{ product_name }} include the following human-readable indicators:

- A visible label such as "Generated by AI" or "AI-generated content"
- Where the content is delivered as part of an interface, an "AI" badge or icon
- Where the content is exported (downloaded, copied, or embedded), the AI-generation indicator is preserved in the file metadata or as a visible watermark when feasible

### Machine-readable marking

In compliance with Article 50(2), AI-generated content from {{ product_name }} is also marked in a machine-readable format that can be detected by automated systems:

{{ #content_types includes "image" }}
- **Images:** C2PA (Coalition for Content Provenance and Authenticity) metadata is embedded where supported. Image EXIF/IPTC fields include AI-generation provenance.
{{ /if }}
{{ #content_types includes "video" }}
- **Video:** C2PA metadata is embedded in supported formats. Where C2PA is not available, video metadata fields indicate AI generation.
{{ /if }}
{{ #content_types includes "audio" }}
- **Audio:** Audio metadata fields and (where feasible) inaudible watermarking indicate AI generation.
{{ /if }}
{{ #content_types includes "text" }}
- **Text:** Where exported in formats supporting metadata (DOCX, PDF), the document properties include "AI-generated" tagging. For plain-text exports, a header or footer line indicates AI generation.
{{ /if }}

## Limitations of marking

We acknowledge that:
- Machine-readable markers can be removed by determined actors. Our marking is implemented in good faith but is not tamper-proof.
- Some output formats (such as plain text copied without metadata) may lose machine-readable markers.
- Standards for AI content marking (notably C2PA and the upcoming EC code of practice for AI-generated content disclosure) are still evolving. We update our practices as standards mature.

## User responsibilities

If you use {{ product_name }} to generate content for further use:
- Do not remove or alter AI-generation markers without a clear lawful purpose
- When publishing AI-generated content publicly, retain visible disclosures
- For content used to inform the public on matters of public interest, the deployer (the publishing entity) has additional Article 50(3) disclosure obligations

{{ #if public_interest_content }}
## Article 50(3) — Public-interest text disclosure

Because {{ product_name }} may be used to generate text published to inform the public on matters of public interest, deployers should be aware of Article 50(3): the deployer must disclose that the text has been artificially generated or manipulated, unless an editorial process under human responsibility applies and the deployer holds editorial responsibility for the publication.

We recommend deployers adopt one of the following patterns:
- A clear "Written with AI assistance" disclosure on the published article
- A standardized AI-disclosure page linked from public content
- An editorial review log recording which articles used AI generation
