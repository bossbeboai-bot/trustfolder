# Packaging Skill

## When to use this skill

- A new template is added to Tier 2 or Tier 3
- The README copy at the top of the pack needs an edit
- A folder name changes (e.g., `02-governance/` → `02-policy-and-governance/`)
- A conditional doc (`t1-03-deepfake-notice`, `t1-04-emotion-recognition-notice`, `t2-12-out-of-scope-handoff`) needs new trigger logic
- A customer reports their ZIP looks disorganized
- The Tier 1 snapshot generator (`engine/src/snapshot.ts`) lands and needs delivery wiring
- The Notion-import experience needs polish (filenames, frontmatter, link structure)

## Reference docs

- Packaging structures: `docs/10-world-class-product-standards.md` §10 (canonical layouts per tier)
- Premium output rules: `docs/10-world-class-product-standards.md` §5 (every doc must include all 9 sections)
- Pricing-tier mapping: `docs/03-pricing-and-tiers.md` (tier numbers ↔ deliverables)
- Code: `engine/src/package.ts`, `engine/src/generate.ts`, `engine/src/deliver.ts`

## Procedure

1. **Identify the tier and folder family.**
   - Tier 2 ($499 Disclosure Pack) — flat: `disclosures/` + `placement-guide.md` + `legal-review-note.md`
   - Tier 3 ($999 Full Evidence Folder) — 4-folder: `01-disclosures/` + `02-governance/` + `03-evidence/` + `04-legal-review-handoff/` + `sources-and-notes.md`
   - Tier 1 ($99 Snapshot) — single file: `TrustFolder-Readiness-Snapshot.md` + `.pdf` (no folder)
2. **Trace the folder mapping** in `engine/src/package.ts`:
   - Tier 2 logic: `if (doc.template_id === 't1-06-…') → placement-guide.md` etc.
   - Tier 3 logic: `folderForTier3(template_id)` switch.
3. **Add a new template:**
   - Add to the manifest in `engine/src/generate.ts` (`DISCLOSURE_DOCS` for disclosure family, `GOVERNANCE_DOCS` for governance family).
   - Add a routing case to `folderForTier3()` in `engine/src/package.ts` if it's a Tier 3 doc.
   - Update `docs/10` §10 with the new file.
   - Update the README templates in `engine/src/package.ts` (`renderTopReadme`) if the doc deserves prose mention.
4. **Edit README copy:**
   - The top README is autogenerated by `renderTopReadme()` per tier — do NOT hand-write per customer.
   - Keep it under 60 lines; customers skim.
   - Always include the canonical disclaimer block (`disclaimerBlock()`) at the bottom.
5. **Add a conditional doc:**
   - The template's `applies(ctx)` function in `generate.ts` decides whether it appears.
   - Test both branches: a customer where it DOES apply and one where it does NOT.
   - Update the smoke test to cover the new conditional.
6. **Polish for Notion import:**
   - Filenames: kebab-case, ASCII-only, ordered by `01-`, `02-` numeric prefixes inside folders.
   - Each doc starts with `# Title` (single H1).
   - No nested frontmatter blocks.
   - Cross-references between docs use relative paths: `../03-evidence/02-05-evidence-tracker.md`.
7. **Verify the ZIP locally** before merging:
   - Run a sandbox order through `tier_2` and `tier_3`.
   - Download the ZIP from Supabase Storage signed URL.
   - Open it; confirm folder structure matches `docs/10` §10 exactly.
   - Drag into Notion; confirm import preserves folder hierarchy.
8. **Update `manifest.json` consumers** if you added new fields — keep backward compatibility.

## Anti-patterns

- **Hand-writing the top README** — it's generated; per-customer hand-writes break at scale.
- **Adding a doc to the manifest without adding it to `folderForTier3()`** — the doc generates but lands in the default `02-governance/` folder, which is wrong for evidence/handoff docs.
- **Naming files with spaces or non-ASCII** — breaks Notion / cross-platform unzip.
- **Mixing Tier 2 and Tier 3 docs in the same ZIP** — Tier 2 is disclosures only, by design. The customer can upgrade later.
- **Skipping the disclaimer block** in any doc or README — every customer-facing surface ends with it.
- **Using `placement-guide.md` in Tier 3** — it's a Tier 2-only file (Tier 3's equivalent is the `04-legal-review-handoff/` folder).
- **Dropping `sources-and-notes.md` from Tier 3** — it's the consolidated provenance file; required.

## Definition of done

- The ZIP layout for the changed tier matches `docs/10` §10 exactly.
- A test customer order produces the expected file count and folder structure.
- README still includes title, generation date, doc count, "How to use this pack" section, and the disclaimer block.
- `manifest.json` reflects the new doc(s) with `template_id`, `filename`, `confidence_band`, `citations`.
- Notion import preserves the folder hierarchy.
- Smoke tests B2 (Tier 2) and B3 (Tier 3) still pass.
